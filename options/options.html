Gemini API

Ключ можно получить на aistudio.google.com/apikey. Ключ хранится только локально в этом браузере (chrome.storage.local) и используется только для запросов к Gemini API напрямую с вашего устройства.

Контекст о вашем опыте

Опишите свободным текстом, кто вы, чем занимались, что вам интересно и как вы обычно рассказываете о себе. Это будет использовано вместе с резюме, чтобы генерировать ответы на сложные вопросы анкет вакансий (например "Why do you want to work here?") в вашем стиле.

Резюме (файлы)

Загрузите одно или несколько резюме в формате PDF или DOCX. При автозаполнении, если на странице найдено поле загрузки резюме, в popup появится меню — выбранный файл будет реально подставлен в это поле. Текст резюме также используется для генерации ответов на вопросы вакансий. Резюме по умолчанию используется, если вы не выберете другое в меню.
